Creating Original Games
After the chess competition, I began developing my own activities and games. I mainly used chess boards as my primary material since that's what was available at the school.

I continued helping with the "contra turno" class
I also had my own dedicated class with smaller groups
Format: 3 grade levels, 3 class periods
Each period, one group from each grade would come to my class
The following week, students would rotate so everyone could participate
This rotation system continued until the end of 2024
