# Playable tutorials: future work

Planning context only. For implemented behavior, read [overview.md](../../tutorials/overview.md) and [technical-contract.md](../../tutorials/technical-contract.md).

## Current starting point

Crown Chase is the first complete playable tutorial. Its shared lifecycle/history and game-owned lesson have code and browser verification records, but no classroom validation. The shared contract remains provisional.

## Possible next integration

Caça Soma is the intended second integration because its custom number-selection and submission flow can test whether the shared foundation is useful outside a board game. [caca-soma-outline.md](caca-soma-outline.md) is a tentative compatibility example, not its final lesson design.

Its current gameplay and mode controls need to inform any future tutorial. A core lesson followed by one useful mode introduction could exercise independently tracked identities and return behavior. No Caça Soma playable tutorial or multi-lesson presentation queue exists yet.

## Later possibilities

- Review tutorial clarity, feedback duration, hint behavior, and transfer to normal play with children.
- Revise or stabilize the shared contract after a second actual integration.
- Add shared capabilities only where concrete integrations justify them.
- Consider mode-specific or contextual help, such as Ajuda or Por que isso aconteceu?, where they solve a real learning need.
- Expand to other games individually, using their own rules and presentation.
- Define lifecycle analytics only if there is a useful measurement purpose; none is implemented in the shared core today.

These are directions for later decisions, not additional requirements for the existing Crown Chase lesson or a fixed rollout procedure.
